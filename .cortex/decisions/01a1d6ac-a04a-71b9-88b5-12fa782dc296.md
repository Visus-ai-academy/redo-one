A API fica em outra origem e autentica pelo cookie httpOnly. No navegador, o cliente do Kubb usa credentials: 'include'; no SSR, um interceptor do cliente põe na chamada à API o cookie que o navegador mandou ao front (createIsomorphicFn + getRequestHeader). A rota pathless _app tem um beforeLoad que chama GET /sessao (401 vira null) e, sem sessão, redireciona para /login?redirect=<caminho>, aceitando só caminho interno. As telas chegam desenhadas, sem piscar. Rejeitados: telas autenticadas só no cliente (ssr: false), que abririam sempre em esqueleto, e um proxy /api no front, que mudaria o deploy e o CORS. A guarda é só navegação; quem barra é a API. Recomendação do agente, aceita pelo usuário.
