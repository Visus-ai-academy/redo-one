O usuário pediu commits conforme o trabalho avança e corrigiu quando uma branch foi criada: 'faça direto na main, em nenhum momento pedi para criar branch'. Cada passo com testes verdes vira um commit Conventional Commits na main, sem Co-Authored-By. Não criar branches nem abrir PR; push só sob pedido.
