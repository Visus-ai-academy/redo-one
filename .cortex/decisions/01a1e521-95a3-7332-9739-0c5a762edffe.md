Decidido com o usuário em 15/11/2026 ("quero conseguir digitar nos selects").

- O `Select` do kit decide sozinho: até 7 opções é o Select do Base UI; acima disso vira Combobox do Base UI com o campo "Buscar na lista" dentro do popup, filtrando sem acento e sem maiúscula, e "Nada encontrado para “x”." quando não acha. O texto digitado é limpo ao fechar.
- O limite 7 é regra de interface, não de negócio, por isso fica no código (`LIMITE_SEM_BUSCA`).
- Lista grande que vem da API por busca (ex.: exames) continua no `BuscaSelecao`.
