Decidido em 16/11/2026 durante a Fase 3.

- Porta `ARMAZENAMENTO_ARQUIVOS` com o SDK v3 da AWS (qualquer serviço compatível com S3); metadados na tabela `arquivos`. O navegador envia direto ao storage: a URL de envio assina o tamanho exato (o storage recusa outro tamanho) e vale 10 min; a API confere que o arquivo chegou antes de criar a importação e enfileirar o job na mesma transação. A API só lê o arquivo em stream no job.
- Dev: **RustFS** no docker-compose. A MinIO parou de publicar imagens; o SeaweedFS sem configuração não confere assinatura nem responde CORS. `storage:preparar` cria o bucket e o CORS a partir de `CORS_ORIGIN`. Sem S3 configurado a API sobe e o uso explica o que falta.
- A planilha da MobileMed tem o nome do paciente: baixá-la exige `importacao.arquivo.baixar` (sensível) e cada download vira evento de auditoria (`importacao`/`arquivo_baixado`).
- Leitura do XLSX com `read-excel-file` (exceljs sem release desde 2023): 80 mil linhas em ~1 s e ~100 MB.
